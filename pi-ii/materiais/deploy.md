# 🧠 Visão Geral

Um sistema completo geralmente tem:

```

Frontend → Backend → Banco → Storage

```

👉 E cada parte pode usar um serviço diferente (todos free)

---

# 🌐 Frontend

## 🔥 Melhores opções FREE

* Vercel
* Netlify
* Cloudflare (Pages)
* GitHub (Pages)

---

## 🧠 Quando usar cada um

### 🟢 Vercel

* Melhor pra React / Next.js
* Deploy automático com Git
* Muito usado profissionalmente

👉 Free: ~100GB bandwidth/mês

---

### 🟢 Netlify

* Muito fácil (até drag and drop)
* Tem forms e funções

👉 Free: 100GB + build minutes

---

### 🟢 Cloudflare Pages

* Melhor performance global
* Integra com Workers

👉 Free: praticamente ilimitado

---

### 🟢 GitHub Pages

* Ideal pra projetos simples / docs
* 100% grátis

---

# ⚙️ Backend (API)

## 🔥 Opções FREE

* Render
* Fly.io
* Google Cloud (Cloud Run)
* Vercel (serverless)

---

## 🧠 Explicação

### 🟢 Render

* Fácil pra Node.js (Express)
* Deploy automático via Git
* Tem banco integrado

👉 Problema: dorme se ficar inativo

---

### 🟢 Fly.io

* Roda Docker
* Edge global

👉 Free: VMs + bandwidth limitado

---

### 🟢 Cloud Run

* Roda containers
* Escala automaticamente

👉 Free: milhões de requests/mês

---

### 🟢 Vercel Functions

* Serverless
* Fácil, mas limitado

---

# 🗄️ Banco de Dados

* Supabase

* Neon

---

## 🧠 Explicação

* Melhor pra quem usa Node (tu usa)

### 🟢 Supabase

* Banco + Auth + API pronto
* alternativa ao Firebase

### 🟢 Neon / PlanetScale

* SQL moderno (PostgreSQL / MySQL)

# 🧱 Stack 100% Free (Recomendado)

## 🟢 Simples (iniciante)

* Frontend → Vercel
* Backend → Render

* Frontend → Cloudflare Pages
