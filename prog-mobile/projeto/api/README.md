# 📚 API ENEM

API simples para ser consumida por um app de estudos focado no ENEM.

---

## 💡 Ideia

Servir como backend para fornecer conteúdos de estudo, como:

* matérias
* questões
* dicas
* temas

---

## 🚀 Tecnologias

* Node.js
* Express

---

## 🔗 Possíveis rotas

*(exemplo inicial, pode mudar)*

```http
GET /materias
GET /questoes
GET /dicas
```
