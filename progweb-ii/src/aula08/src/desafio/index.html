Cadastro de Usuário com PHP

Desenvolva um sistema simples de cadastro utilizando HTML + PHP, com validação de dados e feedback ao usuário.

🎯 Objetivo

Criar um formulário HTML que envie dados para um script PHP, validando as informações antes de processar.

📋 Requisitos do Formulário

  • Nome (texto)
  • Email (email)
  • Idade (número)
  • Senha (password)
  • Confirmar senha (password)
  • Gênero (radio: Masculino / Feminino / Outro)
  • Interesses (checkbox: Tecnologia, Esporte, Música)
  • Botão "Cadastrar"

⚙️ Regras de Validação (PHP)

  • Todos os campos são obrigatórios
  • Email deve ser válido
  • Idade mínima de 18 anos
  • Senha deve ter pelo menos 6 caracteres
  • Senha e confirmação devem coincidir

📌 Comportamento Esperado

  • Exibir mensagens de erro claras quando houver problemas
  • Se tudo estiver correto, mostrar "Cadastro realizado com sucesso"
  • Exibir os dados (exceto a senha)

🚀 Extras (Opcional)

  • Manter dados preenchidos após erro
  • Sanitizar entradas
  • Organizar erros em um array

💪 Desafio Bônus

  • Salvar dados em JSON ou banco de dados
  • Criar sistema de login simples
